# Changelog

All notable changes to this package will be documented in this file.

## [1.1.0] - 2026-11-16
- Added `TriggerEventSO` sequence action with `EventSoRaiser`.
- Added dependency on `com.raxy.event`.

## [1.0.0] - 2026-11-07
- Initial release of RAXY Sequence.
- Added `ISequenceable` interface with scheduling properties and `ExecuteAsync`.
- Added `SequenceableBase` abstract base class with serialized Odin fields.
- Added `SequenceRunner` for executing unified sequences.
